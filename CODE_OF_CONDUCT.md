# Code of Conduct

Be respectful. Disagree about code, not about people.

Harassment, personal attacks, and discriminatory language or behaviour aren't
welcome here, in issues, pull requests, discussions, or any other project space.

If someone violates this, report it by opening an issue with `[conduct]` in the
title, or by contacting the maintainer directly through their GitHub profile.
Reports will be handled privately, and repeated or serious violations may result
in being blocked from the project.
